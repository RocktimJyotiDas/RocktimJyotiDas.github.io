Dynamics Model for Deformable Object Manipulation

Rocktim Jyoti Das,
University of Maryland, College Park, MD, USA
Project Presentation

Motivation

Robotic manipulation and interaction with deformable objects require models that go beyond static geometry or purely visual reconstruction. While recent methods can reconstruct high-fidelity 3D shape and appearance from RGB-D data, they often lack physically grounded dynamics, limiting their ability to predict future states, reason about forces, or generalize to unseen interactions. A true physical digital twin should capture not only how an object looks, but also how it moves, deforms, and responds to contact under external actions.

To address this, we aim to infer material parameters directly from real-world observations, enabling simulations that faithfully reproduce observed object motion and can be reused for downstream tasks such as planning, simulation, and interaction.

Related Work

Spring–mass models are widely used for deformable object simulation due to their simplicity and efficiency. Recent works (e.g., PhysTwin) successfully integrate spring–mass dynamics with optimization-based inverse modeling to reconstruct deformable objects from sparse video observations. However, spring–mass systems rely on fixed connectivity and local linear assumptions, making them less suitable for large deformations, bending-dominated motion, or topology-changing phenomena.

Continuum mechanics–based methods such as FEM and MPM offer stronger physical grounding but have traditionally been difficult to integrate with perception pipelines and differentiable optimization. Recent advances in differentiable simulation frameworks (e.g., Warp) enable backpropagation through complex physics solvers, opening the door to physically grounded inverse modeling driven by real data.

Proposed Idea

We extend the PhysTwin paradigm by replacing the spring–mass prior with a continuum-based Material Point Method (MPM). The key idea is to keep the same supervision signal—tracked 3D motion from RGB-D observations—while upgrading the underlying dynamics model to a physically richer continuum formulation.

MPM offers three practical advantages for inverse modeling of deformable objects: it naturally supports large deformations without relying on mesh connectivity, computes internal forces from stress via a constitutive model, and enables optimization over physically meaningful parameters such as Young’s modulus and density. Crucially, the simulator remains fully differentiable, allowing gradients to flow from image- or trajectory-level losses back to material parameters.

The result is an end-to-end pipeline that estimates spatial material properties from observed motion while preserving physical interpretability and generalization to novel interactions.

MPM PhysTwin: Differentiable Continuum Dynamics

Particle State and Constitutive Model

We represent the object as a set of Material Point Method (MPM) particles. Each particle stores a local continuum state: position xp, velocity vp, deformation gradient Fp, affine velocity field Cp, volume Vp, and density ρp. This particle-based continuum representation avoids explicit mesh connectivity while still supporting stress-based internal forces.

We use a compressible isotropic Neo-Hookean constitutive model that maps deformation to stress. The material parameters are Young’s modulus E (optimized, controls stiffness), density ρ (optimized, controls inertia), and Poisson’s ratio ν (fixed, controls volumetric response and improves numerical stability). In the simulator, parameters enter as:

(E, ν) → (μ, λ) → stress,    ρ → mass and inertia

Forward MPM Simulation (Differentiable)

The forward dynamics are advanced using the standard Particle → Grid → Particle (P2G–Grid–G2P) loop. All steps are differentiable, so predicted trajectories depend explicitly on E and ρ.

Forward Simulation Pseudocode

Given material parameters: E, ρ   (ν fixed)
Precompute: μ, λ = f(E, ν)

for each timestep t:

  # P2G: particles → grid
  for each particle p:
      m_p = ρ_p * V_p
      σ_p = StressNeoHookean(F_p; μ, λ)
      scatter m_p, m_p v_p, and stress contributions to grid nodes

  # Grid solve
  for each grid node i:
      accumulate internal forces from stress
      add external actions (gravity, push/gripper, collisions, BCs)
      update grid velocity v_i using total forces and grid mass

  # G2P: grid → particles
  for each particle p:
      v_p  = interpolate grid velocities
      x_p += Δt * v_p
      ∇v_p = interpolate grid velocity gradients
      F_p  = (I + Δt ∇v_p) F_p
      C_p  = APIC affine update

Supervision and Loss Function

Supervision is obtained from RGB-D videos by tracking 3D Gaussian centers, which provide sparse but reliable object motion. We supervise only 3D point motion (not pixels). At each frame t, we compare simulated particle positions Xtsim to tracked Gaussian centers Xtgt using the Chamfer distance:

Lt = Chamfer( Xtsim, Xtgt )

Chamfer distance is appropriate because there are no explicit correspondences, tracked points can be missing due to occlusion, and the metric enforces global alignment of shape and motion.

Differentiable Backpropagation

The loss is computed in PyTorch, and gradients with respect to simulated particle positions are injected into the MPM solver. Using Warp’s automatic differentiation, gradients propagate backward through the entire MPM pipeline—G2P, grid solve, P2G, stress computation, constitutive parameters (μ, λ), and finally the material parameters (E, ρ). This enables end-to-end optimization of physically meaningful material properties directly from observed motion.

Experimental Setup

We evaluate our method on deformable object interaction sequences from the PhysTwin dataset, focusing on cloth and rope manipulation scenarios. For each sequence, RGB-D videos are used to extract tracked 3D Gaussian centers, which provide sparse but reliable supervision of object motion. MPM particles are initialized from the first frame, and the recorded external actions (e.g., pushes and gripper motion) are replayed in simulation to match the real interaction conditions. We then optimize material parameters by minimizing motion error over time, producing an MPM simulation that best explains the observed trajectory. All experiments are executed using a differentiable MPM solver implemented in Warp.

Per-sequence pipeline

  1. Use RGB-D videos to extract tracked 3D Gaussian centers.
  2. Initialize MPM particles from the first frame.
  3. Replay external actions (pushes, gripper motion) in simulation.
  4. Optimize material parameters by minimizing motion error over time.

Implementation

All simulations are run using a differentiable MPM solver implemented in Warp.

Results

Qualitative results show that optimized MPM simulations can closely follow real object motion under interaction. Compared to unoptimized or spring–mass baselines, MPM better preserves large-scale deformation, produces smoother and more realistic motion, and avoids tuning mesh connectivity or spring parameters. Visualizations overlay simulated particles (green) with ground-truth motion (white), demonstrating improved trajectory alignment across frames.

Observations and Future Work

Observations

  • MPM provides stronger physical priors than spring–mass models, enabling more realistic continuum behavior under large deformations.
  • Optimizing material parameters (E and ρ) significantly improves motion fidelity and trajectory alignment.
  • A fixed Poisson’s ratio (ν) is sufficient to obtain stable and physically meaningful material inference in practice.

Future Work

  • Extend the framework to support plasticity, fracture, and damage models within the MPM formulation.
  • Enable multi-material objects with spatially varying physical properties.
  • Incorporate additional supervision signals such as tactile sensing or force feedback.
  • Improve particle initialization and robustness under extreme deformations and contact events.
