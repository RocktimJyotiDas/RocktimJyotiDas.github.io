# UMD Robotics Reading Group

Static page for the UMD Robotics Reading Group (Fall 2026). Weekly on Tuesdays, 5–6 pm.

- `index.html` — schedule and info page (styled to match the main site via `../../stylesheet.css`).
- `slides/` — presentation files, named `YYYY-MM-DD-<topic>.<ext>`.

To add a session: fill in the matching `TBD` row in the schedule table in `index.html`,
add the presenter/topic and paper link, and drop the slides in `slides/` with a `slides` link on the row.
